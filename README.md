# postech-fase2-restaurantes-app
Sistema de gestão compartilhada de restaurantes (Tech Challenge Fase 2): CRUD de tipos de usuário, cadastro de restaurantes e itens de cardápio. Construído em Clean Architecture com Java 21, Spring Boot 3.5, Spring Security/JWT, PostgreSQL, Flyway, Docker Compose, Swagger, HATEOAS e testes com JUnit, Mockito, Testcontainers e ArchUnit.
